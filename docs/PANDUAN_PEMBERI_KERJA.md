## 🎯 Ringkasan Alur Pemberi Kerja (Stand Booth)
Sebagai perwakilan HRD / Rekruter industri di booth expo, Anda dapat:
1. Masuk menggunakan akun resmi yang telah dialokasikan untuk masing-masing dari **23 Stand Industri**.
2. Mengelola profil perusahaan, nomor booth stand, dan kontak PIC WhatsApp.
3. Membuka **Kamera Barcode Scanner Stand** untuk scan QR Code di ponsel pelamar saat mendatangi booth Anda.
4. Melakukan verifikasi kehadiran fisik dan seleksi berkas secara langsung di tempat (*Walk-in Verification*).
5. Mengubah status pelamar secara berjenjang:
   - **Check-in Stand** (*Terverifikasi Hadir*)
   - **Wawancara Booth** (di meja booth)
   - **Lolos Seleksi** (*Diterima Kerja*)
   - **Ditolak**
6. Menulis catatan hasil wawancara atau pengarahan berkas bagi pelamar.

## 🚀 Panduan Operasional di Meja Booth

### 1. Masuk ke Dashboard Stand
1. Buka [https://bme.smknegeri1magelang.sch.id](https://bme.smknegeri1magelang.sch.id), klik **Masuk / Daftar** di kanan atas.
2. Masukkan Username Stand (contoh: `HkGoldStandA3` atau `A3`) atau alamat email resmi.
3. Masukkan kata sandi booth Anda dari tabel di atas (klik ikon mata jika ingin melihat kata sandi).
4. Klik **Masuk Portal**. Anda akan langsung diarahkan ke halaman **Stand & Verifikasi**.

### 2. Memeriksa Informasi Booth & Pipeline
* Pada bagian atas dashboard, periksa:
  - Nomor Stand (contoh: *Stand A3*)
  - Nama Perusahaan & Kontak PIC WhatsApp
  - Visual Pipeline Seleksi:
    1. **Check-in Stand**: Jumlah peserta yang hadir fisik di booth Anda.
    2. **Wawancara Booth**: Jumlah pelamar yang dipanggil interview di meja stand.
    3. **Lolos Seleksi**: Jumlah kandidat yang berhasil dinyatakan diterima kerja.

### 3. Pemindaian QR Code Pelamar di Meja Booth
1. Ketika pelamar datang dan menunjukkan **Kartu Peserta Digital** di ponselnya, klik tombol **Buka Scanner Barcode Stand**.
2. Izinkan akses kamera perangkat (laptop webcam atau kamera smartphone).
3. Arahkan kamera ke QR Code peserta.
4. Sistem secara instan:
   - Mencatat presensi fisik kunjungan stand ke database.
   - Mengubah status lamaran menjadi **Terverifikasi di Stand**.
   - Menampilkan biodata lengkap, asal sekolah/kampus, jurusan, dan tautan CV/portofolio pelamar.
   - *Catatan*: Jika perangkat tidak memiliki kamera atau QR rusak, gunakan kolom input manual NIK / Token di bawah jendela scanner.

### 4. Melakukan Wawancara On-The-Spot
1. Jika pelamar memenuhi kualifikasi awal, klik tombol **Panggil Wawancara**.
2. Lakukan wawancara singkat atau tes tertulis di booth.
3. Setelah wawancara:
   - Klik **Terima Pelamar** jika dinyatakan lolos ke tahap berikutnya.
   - Klik **Tolak** jika belum sesuai kualifikasi.
   - Berikan catatan industri pada kolom yang tersedia sebagai rekam jejak.

### 5. Mengelola & Mengedit Lowongan Kerja Aktif
1. Pada Dashboard Stand, klik tab **Kelola Lowongan Aktif** (terletak di sebelah tab *Daftar Pelamar Stand*).
2. Anda dapat memantau seluruh lowongan aktif perusahaan Anda beserta rincian kuota, gaji, kualifikasi, dan jumlah pelamar yang masuk.
3. **Mengubah / Edit Lowongan**: Klik tombol **Edit Lowongan** pada posisi yang ingin diubah. Anda dapat menyesuaikan kuota pelamar, rentang gaji, kualifikasi, maupun berkas persyaratan.
4. **Membuka Lowongan Baru**: Klik tombol **+ Tambah Lowongan Baru** di kanan atas untuk mempublikasikan posisi lowongan tambahan secara langsung.
5. **Menutup / Menghapus Lowongan**: Klik tombol **Hapus / Tutup** pada kartu lowongan jika kuota telah terpenuhi atau posisi sudah ditutup.

### 6. Mengubah Alamat Kantor, Logo Perusahaan & Informasi Profil Stand
1. **Menu Edit Alamat Cepat**: Klik tombol **Edit Alamat** di bagian atas Dashboard Stand atau buka tab **Edit Alamat** (di sebelah tab *Kelola Lowongan Aktif*), masukkan alamat lengkap kantor/perusahaan Anda, lalu klik **Simpan Alamat Perusahaan**.
2. **Edit Profil Stand Lengkap**: Pada header Dashboard Stand, klik tombol **Edit Profil Stand**.
3. **Unggah Logo Baru**: Klik tombol **Pilih Gambar Baru** untuk memilih file gambar logo perusahaan (format PNG, JPG, SVG, atau WebP). Logo baru akan langsung tersimpan ke Supabase dan otomatis tampil di kartu direktori, denah lantai expo, dan daftar lowongan.
4. **Ubah PIC, Alamat & Deskripsi**: Sesuaikan nama perusahaan, kontak PIC WhatsApp, **Alamat Kantor / Perusahaan**, dan profil singkat perusahaan, lalu klik **Simpan Data Stand**.

### 7. Ekspor Data Pelamar Stand ke Format Excel (.xlsx)
1. Di tab **Daftar Pelamar Stand**, klik tombol hijau **Ekspor Excel (.xlsx)**.
2. File spreadsheet resmi Microsoft Excel akan otomatis diunduh, memuat daftar nama pelamar, NIK, nomor WhatsApp, email, asal sekolah/kampus, link CV digital, status wawancara, dan tanggal verifikasi fisik di stand Anda.

### 8. Lupa Kata Sandi Akun Stand
* Jika perwakilan stand lupa kata sandi, klik tautan **Lupa kata sandi?** pada modal login.
* Masukkan username stand (contoh: `HkGoldStandA3` atau `A3`). Sistem akan mengonfirmasi identitas stand dan mengarahkan kembali ke kata sandi resmi pada Buku Panduan ini atau meja sekretariat Panitia BKK / UNTIDAR di Graha Krida Wiyata.
