## 🎯 Ringkasan Alur Pemberi Kerja (Stand Booth)
Sebagai perwakilan HRD / Rekruter industri di booth expo, Anda dapat:
1. Masuk menggunakan akun resmi yang telah dialokasikan untuk masing-masing dari **20 Stand Industri**.
2. Mengelola profil perusahaan, nomor booth stand, dan kontak PIC WhatsApp.
3. Membuka **Kamera Barcode Scanner Stand** untuk scan QR Code di ponsel pelamar saat mendatangi booth Anda.
4. Melakukan verifikasi kehadiran fisik dan seleksi berkas secara langsung di tempat (*Walk-in Verification*).
5. Mengubah status pelamar:
   - **Hadir & Terverifikasi**
   - **Panggilan Wawancara** (di meja booth)
   - **Lolos Diterima**
   - **Ditolak**
6. Menulis catatan hasil wawancara atau pengarahan berkas bagi pelamar.

## 🚀 Panduan Operasional di Meja Booth

### 1. Masuk ke Dashboard Stand
1. Buka website portal, klik **Masuk / Daftar** di kanan atas.
2. Masukkan email dan kata sandi stand industri Anda dari tabel di atas.
3. Anda akan langsung diarahkan ke halaman **Stand & Verifikasi**.

### 2. Memeriksa Informasi Booth
* Pada bagian atas dashboard, periksa:
  - Nomor Stand (contoh: *Stand A1*)
  - Nama Perusahaan & Kontak PIC
  - Total Lamaran Masuk, Terverifikasi, dan Wawancara.
* Jika ingin memperbarui kontak PIC atau deskripsi perusahaan, klik **Edit Profil Stand** -> perbarui data -> klik **Simpan Data Stand**.

### 3. Memindai QR Code Pelamar di Meja Booth
Saat pencari kerja mendatangi booth Anda:
1. Minta pelamar membuka **Kartu QR Digital** di layar ponsel mereka.
2. Di dashboard Anda, klik tombol amber **"Scan Barcode Pelamar"**.
3. Arahkan kamera laptop atau smartphone Anda ke kode QR pelamar:
   - Kamera langsung mengenali kode dalam hitungan detik.
   - Layar otomatis menampilkan data lengkap pelamar: Nama Lengkap, Asal Sekolah/Kampus, Jurusan, NIK, dan Nomor WhatsApp.
4. **Jika Perangkat Tidak Memiliki Kamera**: Ketik token pelamar (contoh: `BSJ2026-PEL-75600`) atau nomor NIK pelamar pada kotak input manual di bawah viewfinder -> klik **Cari**.

### 4. Tindakan Seleksi & Verifikasi di Stand
Pada kartu data pelamar yang muncul setelah scan:
* **Tombol "Verifikasi Hadir di Stand"**:
  - Digunakan untuk menandai bahwa pelamar telah hadir fisik di booth Anda.
  - Jika pelamar belum pernah melamar online sebelumnya (*walk-in candidate*), sistem otomatis mendaftarkannya ke lowongan utama stand Anda dengan status **`Hadir & Terverifikasi`**.
* **Tombol "Panggil Wawancara"**:
  - Digunakan jika pelamar langsung diarahkan duduk di meja interview booth untuk wawancara teknis/tanya-jawab berkas. Status lamaran berubah menjadi **`Wawancara`**.
* **Tombol "Scan Pelamar Lain"**:
  - Me-reset pemindai dan mengaktifkan kembali kamera untuk melayani antrean pelamar berikutnya.

### 5. Memproses Daftar Pelamar di Tabel
Di bawah kartu ringkasan, terdapat tabel **Daftar Pelamar di Stand**:
* Anda dapat memfilter berdasarkan status (*Semua*, *Menunggu*, *Terverifikasi Stand*, *Wawancara*, *Diterima*, *Ditolak*).
* Gunakan kotak pencarian untuk mencari nama kandidat tertentu.
* Pada kolom **Aksi Seleksi di Stand**, Anda dapat mengklik:
  - Tombol **Hadir**: Menandai verifikasi kehadiran fisik.
  - Tombol **Wawancara**: Menjadwalkan/memanggil wawancara.
  - Tombol **Terima**: Menyatakan pelamar lolos seleksi bursa kerja.
* Klik tombol **Sinkron Data** di pojok kanan atas sewaktu-waktu untuk memperbarui data pendaftar baru secara real-time dari server.
